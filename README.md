# WorldFlow homepage

This directory is the standalone static publication. Entry point: `index.html`.
All styles, scripts, fonts, figures and videos are local under `assets/`.
No build step or external service is required to serve it.

For GitHub Pages, upload this directory's **contents** to a repository, then choose Settings → Pages → Deploy from a branch → main / root. A project subpath is supported because resource URLs are relative. No site has been deployed by this export.

Code links to https://github.com/worldflow-rbs/worldflow. Paper, arXiv, Data and Model currently use placeholder links. Set their URLs in `assets/main.js` when ready. This is a generated publication folder; permanent content changes belong in the authoring project's sources and scripts.

`release-manifest.json` lists every published file, size and SHA-256 checksum.
The source project, private server paths, selection pages and unused media are not part of this publication.
